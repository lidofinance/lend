# Security

This repository is a fork of [Morpho Blue](https://github.com/morpho-org/morpho-blue) maintained for the Lido Lending product.

Vulnerabilities in this repository or in its deployments must be reported to Lido, not to Morpho Labs: report through the [Lido bug bounty on Immunefi](https://immunefi.com/bounty/lido/) or to the Lido security team. The `security@morpho.org` contact found in unmodified inherited files refers to the upstream project; if an issue also affects upstream Morpho Blue, please report it to both teams.

Please do not disclose vulnerabilities publicly before they are triaged and remediated.
