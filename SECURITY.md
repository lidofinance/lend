# Security

This repository contains the LidoLend core, a fork of Morpho Blue maintained for the Lido Lend product.

Before submitting a report, check the [current Lido Immunefi program and scope](https://immunefi.com/bug-bounty/lido/information/). Repository code and development branches are not automatically in scope. Send findings that do not fit the published scope to [security@lido.fi](mailto:security@lido.fi), the contact listed in Lido's [security.txt](https://lido.fi/.well-known/security.txt).

Report Lido-specific issues to Lido, not to Morpho Labs. If the same issue also affects upstream Morpho Blue, also send it privately to [security@morpho.org](mailto:security@morpho.org). Do not disclose a vulnerability publicly before it has been triaged and remediated.
